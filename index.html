Questions fréquentes

Faut-il créer un compte pour consulter le site ?
Non, le site et ses contenus sont accessibles librement.

Comment s’inscrire à une formation ?
Choisissez une formation et envoyez le formulaire via WhatsApp. L’équipe vous confirmera les modalités et le tarif de 20 $.

Conditions d’utilisation

Les informations du site présentent les activités et formations Yuniom. Les dates, disponibilités et modalités sont confirmées par l’équipe avant toute inscription. Les contenus sont destinés à un usage personnel et professionnel responsable.

Confidentialité

Les formulaires préparent un message que vous choisissez d’envoyer à Yuniom sur WhatsApp. Les brouillons sont enregistrés uniquement dans le stockage local de votre navigateur ; le site statique ne les transmet pas à une base de données.

Formulaire Yuniom

Remplissez les informations demandées. Les données seront envoyées sur WhatsApp.
